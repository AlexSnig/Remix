02 · preflight та інсталяція

Працювати лише з точним serial

Новий телефон і вже commissioned телефон мають різні процедури. Не виконувати factory reset, uninstall або clear data без окремого письмового дозволу.

×

Стоп-умови нового телефона

Емулятор/не SM-A075F, кілька телефонів, більше одного user, акаунт, системний PIN/пароль, інший Device Owner або музейний пакет. Не обходити guards.

bash .agents/skills/exhibit-motion-release/scripts/\ commission-museum-phone.sh --serial SERIAL \ --apk ExhibitMotion-1.3.20-code25-release.apk \ --preflight-only

Очікування для нового телефона

SM-A075F, один user 0
Accounts: 0; credential NONE
Device Owner відсутній
конфліктних пакетів немає

Встановлення

bash .agents/skills/exhibit-motion-release/scripts/\ commission-museum-phone.sh --serial SERIAL \ --apk ExhibitMotion-1.3.20-code25-release.apk

Скрипт встановлює з -r, перевіряє 1.3.20/code 25 і pulled base.apk, застосовує policies та виконує один reboot.

#

Обов’язкова byte-for-byte перевірка

Отримати шлях через pm path ua.alexsnig.exhibitmotion, витягнути base.apk командою adb pull і звірити його SHA-256 з d8ad4e…ebed49.

03 · Device Owner та kiosk

Постійний HOME і Lock Task

Device Owner застосовується guarded-скриптом лише після чистого preflight і дозволу власника телефона.

bash .agents/skills/exhibit-motion-release/scripts/\ commission-museum-phone.sh --serial SERIAL \ --apk ExhibitMotion-1.3.20-code25-release.apk

Політики без screen taps

Скрипт викликає native policy-compliance Activity, а не координати екрана: HOME, Lock Task, keyguard policy і три fixed permissions застосовуються та перевіряються автоматично.

04 · OTA та operator wizard

Завершити шість перевірок

Samsung OTA на виділеному телефоні

com.wssyncmldm com.samsung.android.app.updatecenter com.sec.android.soagent ota_disable_automatic_update=1

Guarded-скрипт вимикає та перевіряє їх до reboot, потім повторює після boot: Android 16 може сам увімкнути пакети під час першого запуску.

Майстер у застосунку

1

Камера

Підтвердити лінзу за реальним монтажем.

2

Локальне аудіо

Обрати потрібну постать із 20-файлового каталогу.

3

Маршрут

У maintenance — будь-яка A2DP/BLE-колонка; людина натискає «Чую звук».

Продовження

4

Гучність

Зберегти рівень і перевірити фактичну колонку.

5

Калібрування

10 секунд зі стабільною сценою; воно не вмикає датчик.

6

Тест руху

Реальний рух, відтворення, завершення й cooldown.

!

PIN належить оператору

Не записувати й не автоматизувати PIN. У 1.3.20 після його створення «Відкрити операторський режим» доступний навіть до завершення wizard: спочатку ввійти, потім «Підключити або змінити Bluetooth-колонку». Нова колонка замінює старий маршрут лише після «Чую звук». Зміна аудіо скидає route approval і motion test — спочатку оберіть фінальне озвучення.

♫

ADB не чує звук

Назва A2DP/AUX у системі не є доказом чутності. Телефонний динамік ніколи не є запасним виходом.

05 · cold boot та AUTO_START

Розрізняти kiosk і датчик

HOME/Lock Task можуть відновитися, навіть якщо detector auto-start заблокований незавершеним wizard. Це різні докази.

1

До reboot

Усі шість перевірок зелені; операторський PIN задано; kiosk та автозапуск увімкнено.

2

Повний reboot

Guarded-скрипт виконує один commissioning reboot після install/update.

3

Після boot

Якщо authorized ADB відсутній, скрипт один раз перезапускає лише host ADB. Далі повертає blocker без reset телефона.

Ніколи не очищати дані

Оновлення має бути підписане тим самим ключем і мати унікальний вищий versionCode. Для 1.3.20 це code 25.

×

Заборонено під час оновлення

adb uninstall, pm clear, remove-active-admin, factory reset, заміна package name або ключа підпису.

↻

Після install -r потрібен reboot

Package replacement зупиняє foreground service. Ручний action.START не доводить boot resume; потрібен саме action.AUTO_START після reboot.

Відкат

Відкат можливий лише до APK з тим самим підписом і сумісними даними. Не знижувати versionCode через випадковий старий файл і не видаляти поточний застосунок для обходу Android. Спочатку зберегти діагностику й погодити процедуру з власником.
